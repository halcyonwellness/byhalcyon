The Application may be used only to read the Company's own QuickBooks Online financial reports (including Profit and Loss, Balance Sheet, Cash Flow, vendor spend, and budget-versus-actual data) for internal analysis, budgeting, board reporting, and financial operations.

4. Restrictions

The Application does not create, modify, or delete data in QuickBooks Online. It performs read-only retrieval. It is not to be resold, redistributed, or used to access any company other than Halcyon Wellness, Inc.

5. Data Access and Security

The Application accesses QuickBooks Online through Intuit's authorized OAuth 2.0 interface using the "Accounting" scope. Access credentials are stored securely within Google Apps Script property storage associated with the Company's Google Workspace account. Retrieved data is written only to the Company's private Google Sheets.
